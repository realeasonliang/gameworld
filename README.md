## 🕹️ 怎么玩 · How to Play

1. 把仓库克隆 / 下载到本地。
2. 用浏览器打开任意一个 `.html` 文件即可开玩。
3. 游戏内有操作说明（或看屏幕上的按钮）。

```bash
git clone git@github.com:realeasonliang/gameworld.git
```

## 🏷️ 版本号规则 · Versioning

格式：**`主版本.次版本.修订`**（例如 `v2.0.0`），这是全世界通用的 [语义化版本](https://semver.org/lang/zh-CN/) 规则。

| 哪一位 | 什么时候加一 | 真实例子 |
|--------|--------------|----------|
| 主版本 | 加了**全新玩法** | 方块世界新增生存 / 创造模式 → `1.x.x` → `2.0.0` |
| 次版本 | 加了**新内容**，玩法没变 | 航天模拟新增自动驾驶 → `1.2.0` → `1.3.0` |
| 修订   | 修 bug、改文字、调数值 | 修好一个闪退 → `1.0.0` → `1.0.1` |

网站有一个总版本，每个游戏各有一个版本（因为它们的更新速度不一样）。当前版本：

| 项目 | 版本 | 说明 |
|------|------|------|
| 🌍 网站整体 | `v1.0.0` | 首页 / 留言板 / 二维码 |
| 🚀 航天模拟器 | `v1.3.0` | 自动驾驶、行星际导航、空间站对接 |
| ⛏️ 方块世界 | `v2.0.0` | 生存模式 + 创造模式 |
| 🌻 植物大战僵尸 | `v1.0.0` | 塔防 + 答题挑战 |

版本信息统一保存在 `assets/version.js`，**不要手改**，用脚本更新：

```bash
node tools/bump.js                       # 只同步日期和 git hash
node tools/bump.js minecraft major       # 方块世界 2.0.0 → 3.0.0
node tools/bump.js sfs minor             # 航天模拟 1.3.0 → 1.4.0
node tools/bump.js site patch            # 网站 1.0.0 → 1.0.1
```

## 📜 更新日志 · Changelog

### 网站 v1.0.0 · 2026-10-03

### ⛏️ 方块世界 v2.0.0 · 2026-10-03
- **生存模式**：20 点生命（10 颗心）、20 点饱食度（10 个鸡腿），饥饿掉血、吃饱回血、跌落伤害、死亡重生。
- **创造模式**：无限资源、左键瞬间破坏、**双击空格飞行**（空格上升 / Shift 下降）。
- 打猎：牛和羊 5 点血，5 拳打死，掉落牛排 / 羊排，走近自动拾取，按 `9` 选中后右键食用。
- 随时按 `M` 切换模式；存档会一起保存模式、血量、饱食度与背包。

- 侧挂零件、偏心力矩、空间站对接服务、蓝图分享码。

## 🛠️ 关于这个项目 · About This Project

- 全部用原生 **HTML + JavaScript + Canvas / WebGL** 写成，**零依赖、零框架**。
- 每个游戏独立放在自己的文件夹（`games/<游戏名>/`）里，方便维护与持续扩展。
- 首页 `index.html` 是**双语**的：会根据浏览器语言自动显示中文 / 英文，右上角 🌐 可手动切换。
- 由 **Eason Liang** 在课余时间独立开发，并持续更新中。
